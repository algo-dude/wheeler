How to Create a Flex Query

To use Flex Web Service sync, you need to create a Flex Query in IBKR Account Management:

  1. Log in to IBKR Account Management
  2. Go to Reports → Flex Queries
  3. Click "+" (Create) under Activity Flex Query
  4. Configure the query:
    • Query Name: Wheeler Sync (or any name)
    • Date Period: Last 365 Days (or desired range)
    • Sections: Enable Trades and Cash Transactions
    • Format: XML
  5. Save the query and note the Query ID
  6. Go to Settings → Flex Web Service
  7. Generate or copy your Flex Token

Note: Flex queries run against historical data and don't require a live TWS/Gateway connection.

About IBKR Integration

Wheeler connects to Interactive Brokers TWS (Trader Workstation) or IB Gateway to automatically sync your positions.

  • TWS Paper Trading: Port 7497 (default)
  • TWS Live Trading: Port 7496
  • IB Gateway Paper: Port 4002
  • IB Gateway Live: Port 4001

Requirements:

  • TWS or IB Gateway must be running and logged in
  • API connections must be enabled in TWS/Gateway settings
  • If using Docker, ensure network connectivity to TWS host

The sync will import all stock and option positions from your IBKR account into Wheeler for tracking and analysis.
